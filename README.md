# ETB Defensive Point Club – Statistik-App

Offlinefähige Web-App für die Defensiv-Punktestatistik im Basketball: Spieler antippen, Aktion wählen,
Punkte werden automatisch vergeben. Export als PDF, Excel und CSV.

- **App öffnen:** https://jan22-de.github.io/Etb-tracker/
- **Anleitung (PDF):** [docs/anleitung/ETB_DPC_Anleitung.pdf](docs/anleitung/ETB_DPC_Anleitung.pdf)
- **Datenschutz:** Alle Spieldaten bleiben im Browser des jeweiligen Geräts. Es gibt keinen Server.
- **Empfohlen:** Chrome (Android) bzw. Safari (iPhone).

Technische Projektbeschreibung für die Weiterentwicklung: [CLAUDE.md](CLAUDE.md)
